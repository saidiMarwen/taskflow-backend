# TaskFlow

TaskFlow est une application Fullstack de gestion de tâches développée avec Java 21, Spring Boot 4 et Angular 19.

## Technologies

- Java 21
- Spring Boot 4
- Spring Security
- Angular 19
- PostgreSQL
- Docker
- Kubernetes
- JWT
- Maven

## Fonctionnalités

- Authentification sécurisée (JWT)
- Gestion des utilisateurs et des rôles
- CRUD des tâches
- Dashboard
- API REST
- Déploiement Docker/Kubernetes

## Architecture

Frontend : Angular 19

Backend : Spring Boot 4

Base de données : PostgreSQL
